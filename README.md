# ربات تلگرام ثبت و پذیرش ویلا (aiogram 3.x)

این ربات به صورت مرحله‌به‌مرحله اطلاعات کامل ویلا را از مالک دریافت کرده، در دیتابیس SQLite ذخیره می‌کند و خلاصه ویلا به همراه گالری تصاویر را به گروه مدیریت ارسال می‌نماید تا مدیران امکان تایید یا رد درخواست را داشته باشند.

## ویژگی‌ها
- نوشته‌شده با **aiogram 3.x**
- مدیریت حالت‌ها با FSM (پرسش گام‌به‌گام)
- دریافت شماره تماس مالک با دکمه اشتراک‌گذاری مخاطب تلگرام (request_contact)
- دریافت نام مالک، نام ویلا، موقعیت مکانی، متراژ، تعداد خواب، ظرفیت، امکانات و قیمت‌ها (وسط هفته، آخر هفته، تعطیلات، نفر اضافه)
- دریافت تا ۱۰ عکس و ارسال به صورت MediaGroup برای ادمین‌ها
- دیتابیس SQLite (فایل villas.db) با جدول `villas` و فیلد وضعیت (pending / approved / rejected)
- دکمه‌های شیشه‌ای تایید/رد در گروه ادمین‌ها با اعتبارسنجی شناسه مدیر و اطلاع‌رسانی خودکار به مالک ویلا

## راه‌اندازی گام‌به‌گام

### ۱. دریافت توکن ربات از BotFather
1. در تلگرام وارد ربات [@BotFather](https://t.me/BotFather) شوید.
2. دستور `/newbot` را ارسال کنید و نام و نام‌کاربری ربات را انتخاب کنید.
3. توکن ارائه‌شده (شبیه `123456789:AA...`) را کپی کنید.

### ۲. یافتن شناسه‌های ادمین و گروه
1. **شناسه کاربری خود (ADMIN_IDS):** به رباتی مانند [@userinfobot](https://t.me/userinfobot) پیام دهید؛ شناسه عددی شما نمایش داده می‌شود. برای چند ادمین، شناسه‌ها را با کاما جدا کنید (مثال: `123456789,987654321`).
2. **شناسه گروه مدیریت (ADMIN_GROUP_ID):** ربات را به گروه مدیریت اضافه کنید، یک پیام در گروه بفرستید و آن پیام را به رباتی مانند [@JsonDumpBot](https://t.me/JsonDumpBot) فوروارد کنید؛ شناسه گروه (معمولاً با `-100` شروع می‌شود) را یادداشت کنید.
3. حتماً حالت حریم خصوصی ربات را در BotFather (دستور `/setprivacy` ← Disable) غیرفعال کنید تا پیام‌های گروه را دریافت کند.

### ۳. تنظیم فایل .env
فایل `.env.example` را به `.env` کپی کنید و مقادیر واقعی را وارد نمایید:
```bash
cp .env.example .env
```
```env
BOT_TOKEN=توکن-ربات-شما
ADMIN_GROUP_ID=-1001234567890
ADMIN_IDS=123456789,987654321
```

### ۴. ساخت محیط مجازی و نصب وابستگی‌ها
لینوکس / مک:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
ویندوز:
```cmd
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### ۵. اجرای ربات
```bash
python main.py
```
پس از اجرای موفق، پیام راه‌اندازی در ترمینال نمایش داده می‌شود. در تلگرام دستور `/start` را به ربات ارسال کنید تا فرآیند ثبت ویلا آغاز شود.

## فرآیند ثبت ویلا
1. `/start` ← ارسال شماره تماس (دکمه یا متن)
2. نام مالک ← نام ویلا ← موقعیت ← متراژ ← اتاق‌ها ← ظرفیت ← امکانات
3. قیمت‌ها (وسط هفته، آخر هفته، تعطیلات، نفر اضافه)
4. ارسال عکس‌ها (حداکثر ۱۰) و سپس دکمه «اتمام ارسال تصاویر» یا `/done`
5. بررسی خلاصه و تایید نهایی ← ذخیره در دیتابیس و ارسال به گروه ادمین‌ها
6. ادمین‌ها با دکمه‌های «تایید» یا «رد» نتیجه را ثبت و به مالک اطلاع می‌دهند.
